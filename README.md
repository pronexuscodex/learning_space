# learning_space

## Systems & AI Academy

A terminal study companion for self-learners. It covers the core of a computer science degree plus modern AI and defensive security in 21 stages, starting from how computers work and C. It includes spaced repetition, real exercises, a programmer's dictionary, a PDF library and tech watch, all in one dependency-free executable.

- **Install it (recommended):** one command, no administrator rights. It adds the app to your Start Menu or app menu and puts `academy` on your PATH ([details](academy/README.md#install)).
  - Windows (PowerShell): `irm https://raw.githubusercontent.com/pronexuscodex/learning_space/main/install.ps1 | iex`
  - macOS and Linux: `curl -fsSL https://raw.githubusercontent.com/pronexuscodex/learning_space/main/install.sh | sh`
- **Download:** [Releases](https://github.com/pronexuscodex/learning_space/releases), for Linux, macOS, Windows and FreeBSD.
- **Or use a package manager:** `brew install pronexuscodex/academy/academy` after `brew tap pronexuscodex/academy https://github.com/pronexuscodex/learning_space`, or `scoop install academy/academy` after `scoop bucket add academy https://github.com/pronexuscodex/learning_space` ([details](academy/README.md#install)).
- **Read more:** [academy/README.md](academy/README.md).
